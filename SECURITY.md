# Security Policy

Security matters to us. We appreciate responsible reports of potential vulnerabilities.

## Reporting a vulnerability

**Do not publish security vulnerabilities as public GitHub issues or pull requests.**

If a repository has GitHub private vulnerability reporting enabled, use its **Security** tab and select **Report a vulnerability**.

Otherwise, contact us through the [official ENERGIE Solution website](https://www.energiesolution.it/), asking to be connected with the technical maintainer for a confidential security report. Avoid including exploit details or sensitive information in a public form; arrange a secure communication channel first.

Please provide, where appropriate:
- The affected repository and version or commit
- A clear description of the issue and its potential impact
- Minimal, non-destructive reproduction steps
- Suggested mitigations, if known

## Responsible disclosure

Please avoid accessing, altering or exposing other people's data; disrupting services; or sharing vulnerability details publicly before maintainers have had a reasonable opportunity to investigate.

Security support and response times vary by repository. This policy does not promise specific service-level timelines.
