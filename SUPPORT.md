# Support

## Questions and suggestions

For questions about a public repository:
1. Read its README and existing documentation.
2. Search existing discussions and issues.
3. If the repository enables GitHub Discussions, use it for general questions.
4. Otherwise, use an issue template for a reproducible bug or actionable feature suggestion.

For general information about ENERGIE Solution, visit [our website](https://www.energiesolution.it/).

## Security and privacy

Do not share credentials, customer information, personal data, private logs or sensitive configuration in public GitHub posts.

To disclose a vulnerability, follow [SECURITY.md](SECURITY.md).
