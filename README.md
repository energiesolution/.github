# ENERGIE Solution — GitHub Community Files

This repository contains the public organization profile and shared GitHub community templates for ENERGIE Solution.

## Structure

- `profile/README.md` — organization overview displayed on the GitHub profile
- `CONTRIBUTING.md` — general contribution workflow
- `CODE_OF_CONDUCT.md` — expectations for respectful collaboration
- `SECURITY.md` — responsible security disclosure
- `SUPPORT.md` — where to ask questions or report concerns
- `.github/ISSUE_TEMPLATE/` — issue intake forms
- `.github/PULL_REQUEST_TEMPLATE.md` — pull request checklist

GitHub may use eligible default community files from this public repository in organization repositories that do not define their own equivalents. Individual repositories can override these defaults.

For public information, visit [energiesolution.it](https://www.energiesolution.it/).
